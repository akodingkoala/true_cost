# Development for later

Bigger or trickier ideas we're saving until the core extension works well.
Nothing in this folder is code. It's notes and plans.

| File | What's in it |
|---|---|
| [hard-stores.md](hard-stores.md) | Stores that are harder to track: Temu, Shein, TikTok Shop, AliExpress |
| [big-features.md](big-features.md) | Larger features: shared price database, past-price backfill, price chart, and more |

When you start one of these, make a branch for it (for example `git switch -c feature/shein`)
and move the idea out of this folder once it's done.
